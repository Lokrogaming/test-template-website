# test-template-website

Erstellt mit **SiteSmith** aus dem Template **Test Template** (v1.0.0, ID `test-template`).

## Lokal starten

- **Statisches HTML:** `index.html` im Browser öffnen – oder mit Preview-Server:
  ```
  npx serve .
  ```
- **Node-Projekt:**
  ```
  npm install
  npm run dev
  ```

## Deployment

- **GitHub Pages (statisch):** Repo → Settings → Pages → Deploy from branch `main` / `/ (root)`.
  URL-Schema: `https://<user>.github.io/test-template-website/`.
- **Node-Projekt:** `npm run build` → Ordner `dist/` auf Pages / Vercel / Netlify deployen.
